# 常见问题（现象 → 原因 → 怎么办）

日志都在 `~/变量库工厂单人版/日志/`（Windows：`C:\Users\你的用户名\变量库工厂单人版\日志\`）：`launcher.log`（双击入口的过程）、`server.log`（工厂服务）。

## 安装时（Mac）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `install.sh` 说“没找到 Python 3.12 或更新的版本” | 系统自带的 Python 是 3.9，太旧 | `brew install python@3.13`（或从 python.org 装），再运行 `./install.sh` |
| `install.sh` 说“没装 OpenCode” | 没装，或装在不常见的位置 | `brew install opencode`；装在别处的话确认终端里 `opencode --version` 能运行 |
| `install.sh` 说“OpenCode 版本太旧” | 需要 2.2 或更新 | `brew upgrade opencode` 或 `opencode upgrade` |
| “依赖没装上” | 网络连不上 PyPI，或被公司 / 学校网络拦了 | 换个网络或连 VPN 后再运行 `./install.sh` |
| “自检没通过” | 依赖装坏了，或系统缺东西 | 删掉 `.venv` 文件夹再运行 `./install.sh`；还不行把 `/tmp/variable-factory-lite-selftest.log` 最后几十行发给帮你的 AI |
| 提示 `permission denied: ./install.sh` | 脚本没有执行权限（下载 zip 解压时会这样） | `chmod +x *.sh` 后再运行；或用 `bash install.sh` |

## Windows 安装时

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 运行 `.\install.ps1` 提示“因为在此系统上禁止运行脚本” | Windows 默认不让运行 PowerShell 脚本 | 改用 `.\install.cmd`（或双击它），它只给这一个脚本放行，不改系统设置 |
| 说“没找到 Python 3.12 或更新的版本”，可明明刚装了 | winget / 安装包改的 PATH 只对新开的窗口生效；或装 Python 时没勾 “Add python.exe to PATH” | 关掉 PowerShell 窗口重新打开再运行；还不行就重新运行 Python 安装包，选 “Modify” 勾上 PATH |
| 输入 `python` 弹出微软商店 | 那是 Windows 自带的“占位”快捷方式，不是真的 Python | 照上一条装好真的 Python；安装脚本会跳过这个占位的 |
| 说“没装 Git” / “没装 OpenCode” | 没装，或刚装完窗口没重开 | 照提示的 `winget` / `npm` 命令装好，**重开窗口**后再运行 `install.cmd` |
| `npm` 不是内部或外部命令 | 没装 Node.js | `winget install --id OpenJS.NodeJS.LTS -e`，重开窗口后再 `npm install -g @opencode/cli` |
| “依赖没装上” | 网络连不上 PyPI；或 Python 版本太新、有的库还没出 Windows 版 | 换个网络或连 VPN；装 Python 3.13（`winget install --id Python.Python.3.13 -e`）后删掉 `.venv` 文件夹再运行 |
| “自检没通过” | 依赖装坏了 | 删掉 `.venv` 文件夹再运行 `install.cmd`；还不行把 `%TEMP%\variable-factory-lite-selftest.log` 最后几十行发给帮你的 AI |
| 安装或更新时报“文件被占用”“拒绝访问” | 仓库在 OneDrive 里正在同步，或工厂还开着 | 把仓库挪出 OneDrive（如 `C:\Users\你的用户名\variable-factory-lite`）；先运行 `.\.venv\Scripts\python.exe -m lite stop` 再试 |
| 桌面上没有快捷方式 | 建快捷方式失败（极少见，比如桌面被公司策略锁住） | 不影响使用：双击仓库里的 `start.cmd` 打开 |

## 打开时

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击入口后一直没反应 | macOS 在问“是否允许访问文件夹”，弹窗被别的窗口挡住了 | 找到那个弹窗点“允许”；或把仓库挪到家目录下（如 `~/variable-factory-lite`）后重新运行 `./install.sh` |
| 弹窗“没打开成功：端口 8797 被别的程序占着” | 别的程序占了 8797 端口 | Mac：终端运行 `lsof -nP -iTCP:8797 -sTCP:LISTEN` 看是谁，关掉它；或用 `LITE_PORT=8798 ./start.sh` 换个端口打开。Windows：PowerShell 运行 `Get-NetTCPConnection -LocalPort 8797` 看 OwningProcess（进程号），在任务管理器里结束它；或 `$env:LITE_PORT=8798; .\start.cmd` |
| Windows：双击快捷方式后没反应，也没弹窗 | 第一次打开要准备十几秒（后台在开 OpenCode 和工厂服务） | 等半分钟；还没有就看 `日志\launcher.log`，或双击仓库里的 `start.cmd`，窗口里会写出卡在哪 |
| Windows 防火墙问“是否允许访问网络” | Python 或 OpenCode 在本机开了服务端口 | 点“取消”或只勾“专用网络”都行，工厂只在本机用 |
| 弹窗“这台电脑没装 OpenCode” | OpenCode 没装或不在常见位置 | 见上面“安装时” |
| 弹窗“OpenCode 后台没打开” | OpenCode 的后台服务起不来（常见：它要的端口被占） | 终端运行 `opencode service start` 看报什么错；报端口被占就按提示 `opencode service set port <别的端口>` 再试 |
| 弹窗“工厂服务没起来” | 工厂服务启动出错 | 看 `~/变量库工厂单人版/日志/server.log` 最后几行；常见是装坏了，重新运行 `./install.sh` |
| 浏览器没打开 | 默认浏览器没设好，或打开被拦 | 在仓库里运行 `./start.sh`（Windows：`start.cmd`）再试；Mac 在“系统设置 → 桌面与程序坞 → 默认网页浏览器”里选一个，Windows 在“设置 → 应用 → 默认应用”里选 |
| 浏览器里一直是 OpenCode 登录页 | 自动登录没成功 | 关掉这个网页，再双击一次入口 |
| 工厂栏写着“工厂栏没拿到钥匙” | 直接输了网址打开，没带钥匙 | 用桌面入口或 `./start.sh`（Windows：`start.cmd`）打开 |
| 提示“OpenCode 里的工厂工具还没连上” | OpenCode 第一次加载工厂工具要几秒 | 再双击一次入口；或在 OpenCode 里新开一个对话 |

## 用的时候

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 左边 AI 报错，提到 401、invalid api key、unauthorized | 你填的模型 key 不对、过期或没余额 | 终端运行 `opencode auth login` 重新填 key（自己粘贴，不要发给别人）；或在对话框下面把模型换回 OpenCode 自带的免费模型 |
| AI 回答很慢、报网络错误、说“rate limit” | 模型服务忙（免费模型更常见） | 等一会儿，在对话里说“继续”；或换成自己的模型 |
| 工厂栏写“AI 正在……”，左边对话没动静 | AI 停了或没收到 | 点旁边的“提醒 AI” |
| 工厂栏说“这份 PDF 几乎没有文字（可能是扫描版）” | PDF 是图片扫描的，没有文字层 | 换一份能选中文字的 PDF（出版社官网下载的一般可以）；扫描版要先用 OCR 软件转成带文字的 PDF |
| AI 交的候选很少、漏了指标 | AI 只精读了目录里看起来要紧的几页 | 点“让 AI 补漏”，它会去读别的页 |
| 上传数据后红字“缺少这些列” | 文件里的列名和 AI 列的不一样 | 在下面把缺的列对应到文件里的列，点“按对应重新校验”；确实没问题就写理由“放行” |
| 合成一直失败 | 数据和定义对不上，或代码有错 | 看左边对话里的报错；点“让 AI 重做”并说清哪里不对 |
| 合成失败，报错里有 sandbox 字样 | macOS 的沙箱工具 `sandbox-exec` 不可用（极少见） | 把报错发给作者 |
| Windows：合成失败，报错说“合成代码里不能……” | AI 写的代码想联网、开程序、写别处的文件，被拦住了 | 点“让 AI 重做”，告诉它只用 inputs 里的表算 result |
| 在 OpenCode 别的项目里看不到工厂栏的功能 | 工厂只在它自己的工作区里接了工具 | 用桌面入口打开；或在工厂栏点“做新论文” |
| 想从头再来 | — | “全部论文”最下面“恢复出厂”（会彻底删除全部论文、数据和工厂的对话，找不回）；或命令 `./.venv/bin/python -m lite reset --yes`（Windows：`.\.venv\Scripts\python.exe -X utf8 -m lite reset --yes`） |

## 还是不行

运行下面的命令看各部分状态，把输出（不含任何 key）发给帮你的 AI 或作者：

```bash
cd ~/variable-factory-lite
./.venv/bin/python -m lite status
tail -n 30 ~/变量库工厂单人版/日志/launcher.log
```

Windows（PowerShell）：

```powershell
cd $HOME\variable-factory-lite
.\.venv\Scripts\python.exe -X utf8 -m lite status
Get-Content -Tail 30 -Encoding utf8 "$env:USERPROFILE\变量库工厂单人版\日志\launcher.log"
```
